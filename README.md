# Daily Insight V1.8

[開啟 Daily Insight](https://vanessa-app.github.io/daily-insight/)

- iPhone：用 Safari 開啟，選「分享」→「加入主畫面」。
- Android：用 Chrome 開啟，從選單選「安裝應用程式」或「加到主畫面」。
- Windows：用 Edge 或 Chrome 開啟，從網址列或瀏覽器選單安裝。

網站使用既有 GitHub Pages 的 `main` 根目錄部署。GitHub Actions 每天台灣時間 08:00、13:00、18:00 排程更新第一手來源，也能手動執行。網站優先讀取同一儲存庫的最新資料，連線失敗時讀取同站備份。

繁中翻譯使用開源模型在標準 GitHub Actions 執行環境處理，無須付費翻譯 API。機器翻譯標示未經人工校對。閱讀器附官方來源連結及日期，並標示資料的範圍。正式文章圖片與測驗需要個別審核，收藏、已讀及測驗進度保存在該瀏覽器。
